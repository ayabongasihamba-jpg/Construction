# Busywork Construction & Welding Website

## Files
- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — mobile menu, year and WhatsApp quote form
- `assets/` — add the business photos here

## Add real business photos
Put these files inside `assets/`:
- `hero.jpg`
- `project1.jpg`
- `project2.jpg`
- `project3.jpg`

The website has fallback online images if your local images are not present.

## GitHub Pages
1. Create/open a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Commit the files.
4. Go to Settings → Pages.
5. Select Deploy from a branch.
6. Select the `main` branch and `/ (root)`.
7. Save.

The quote form opens WhatsApp to **072 955 8993**.
